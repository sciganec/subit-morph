### **SUBIT‑Lingua v3.0 — Structural Axes (K / T / M)**

SUBIT‑Lingua is built on **three fixed structural axes**.  
Every form in the language is a configuration of these axes combined with vowel‑encoded bit states.

The axes are:

- **K** — internal axis  
- **T** — structural axis  
- **M** — process axis  

These axes define the **geometry** of the form.  
They do **not** encode bits; vowels do.

This document specifies the meaning, role, and function of each axis.

---

# **1. Overview of Axes**

A SUBIT form is defined as:

```
K V1 – T V2 – M V3
```

Where:

- **K / T / M** are fixed consonants  
- **V1 / V2 / V3** are vowels encoding 2‑bit states  

The axes:

| Axis | Consonant | Role | Domain |
|------|------------|-------|---------|
| **K** | K | internal | identity, source, interiority |
| **T** | T | structural | form, orientation, spatial configuration |
| **M** | M | process | dynamics, change, temporal configuration |

These three axes form the **irreducible structural basis** of SUBIT‑Lingua.

---

# **2. K‑Axis (Internal Axis)**

### **Consonant:** K  
### **Domain:** internal, source, identity

The K‑axis represents:

- interiority  
- origin  
- self‑configuration  
- internal state  
- source of structure  

In a form:

```
K V1
```

The vowel V1 encodes the **internal state** of the configuration.

Examples:

- **KA‑…** → internal identity (00)  
- **KE‑…** → internal orientation (01)  
- **KO‑…** → internal variation (10)  
- **KU‑…** → internal emergence (11)

---

# **3. T‑Axis (Structural Axis)**

### **Consonant:** T  
### **Domain:** structure, form, orientation

The T‑axis represents:

- spatial configuration  
- structural relations  
- orientation  
- form and shape  
- arrangement of components  

In a form:

```
T V2
```

The vowel V2 encodes the **structural state**.

Examples:

- **T A** → structural identity (00)  
- **T E** → structural orientation (01)  
- **T O** → structural variation (10)  
- **T U** → structural emergence (11)

---

### **Domain:** process, dynamics, temporal configuration

The M‑axis represents:

- change  
- flow  
- temporal structure  
- dynamic behavior  
- transformation  

In a form:

```
M V3
```

The vowel V3 encodes the **process state**.

Examples:

- **M A** → process identity (00)  
- **M E** → process orientation (01)  
- **M O** → process variation (10)  
- **M U** → process emergence (11)

---

# **5. Why Three Axes?**

The K/T/M system is the **minimal complete structural triad**:

- **K** = what something *is* internally  
- **T** = how it is *structured*  
- **M** = how it *behaves* or *changes*  

This triad appears across:

- systems theory  
- ontology  
- cybernetics  
- linguistics  
- process philosophy  

SUBIT‑Lingua formalizes this triad into a **bit‑driven combinatorial language**.

---

# **6. Axes Are Fixed**

In SUBIT‑Lingua:

- axes never change  
- axes never encode bits  
- axes never reorder  
- axes never expand or contract  
- axes are not optional  

Every form must follow:

```
K – T – M
```

This ensures:

- regularity  
- determinism  
- structural clarity  
- universal composability  

---

# **7. Interaction of Axes**

A form is the **intersection** of three axes:

```
(K state) × (T state) × (M state)
```

This yields:

- 4 states per axis  
- 4 × 4 × 4 = **64 forms**  

Words (form‑pairs) represent **transitions** between these intersections.

Higher‑order forms represent **chains** of intersections.

---

# **8. Summary**

- SUBIT‑Lingua uses **three fixed axes**: K, T, M  
- Axes define **internal**, **structural**, and **process** dimensions  
- Vowels encode **bit states** on each axis  
- A form = **K V1 – T V2 – M V3**  
- Axes are **constant**, **ordered**, and **non‑bit‑bearing**  
- The axes form the **geometric foundation** of the entire language  

This document defines the complete axis system of SUBIT‑Lingua v3.0.
